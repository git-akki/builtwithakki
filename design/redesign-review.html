This pass

  • Light only. No dark variant — every colour is declared, so it stays white whatever the visitor's system is set to. Matches your carousel rule.

  • Testimonials got faces. Coloured initial avatars, five stars, and a quote mark. Real names and real words — Pablo, Oliver, Marco, Shadab.

  • Live sites are rendered, not labelled. Each tile draws a tiny page in that site's colour instead of printing its name.
  • Stat bars. Each number carries a small proportion bar, so 32/42 reads as a fraction rather than just digits.
